# FGM Gold Mining Limited — Demo Website

A responsive five-page corporate website built with Next.js, React, TypeScript and custom CSS.

## Pages
- `/` — Home
- `/about` — About FGM
- `/projects` — Portfolio and project cards
- `/sustainability` — Sustainability commitments
- `/contact` — Contact information and enquiry form

## Run locally
1. Install Node.js 20 or later.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Before publishing
All company facts and project entries marked or implied as demo content must be checked and replaced with verified company information. The five project names, locations, licence status, incorporation year, operating claims, and demo office hours are not verified disclosures. Confirm the supplied telephone numbers and email address with the company. The contact form currently prepares an email using the visitor's mail application; it does not submit to a server.

## Image assets
The website uses local generated demonstration images in `public/images/`. These are visual mockups, not verified photographs of FGM sites, facilities, staff or projects. Replace them with approved company photography before public launch.
